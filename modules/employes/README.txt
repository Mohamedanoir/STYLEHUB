FashionNova — Gestion des Employés
VERSION MAQUETTE EXACTE

La fenêtre est volontairement fixée à 1536 x 1024, comme la capture de référence.
Cela évite les bandes noires, le chevauchement et l'agrandissement des panneaux sur les écrans plus larges.

Ouvrir FashionNova_Employes.pro dans Qt Creator puis:
Build > Clean Project
Build > Rebuild Project
Run

La structure suit la maquette:
- sidebar 245 px
- barre supérieure 65 px
- bannière 128 px
- Informations de l'employé à gauche
- Liste des employés à droite
- Statistiques en dessous
- images/logo inclus
